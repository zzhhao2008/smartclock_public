# SmartClock Public（非触屏版）

> ⚠️ **项目状态：官方维护已终止**  
> 本仓库为**非触屏版**智能桌面时钟的公开代码及资源。官方维护重心现已转移至**触摸屏版本**，此版本将不再更新，但代码仍然可用，欢迎社区自行 fork 与维护。

智能桌面时钟（非触屏版）项目代码及资源文件。该项目基于 Lua 脚本语言开发，适用于搭载特定 RTOS（如合宙 Air 系列、ESP32 等）的嵌入式硬件平台，通过四个物理按键（A/B/X/O）进行交互。

## 📌 主要功能

- **主屏幕**：显示高精度时钟、日期、天气、电量及下一个节日倒计时。
- **多工具集成**：
  - 功能完备的**倒计时/正计时器**。
  - 带有节日高亮的**日历**。
  - 详细的**天气预报**与**生活指数**。
  - 云端同步的**日程表**。
- **远程管理**：支持通过云端配置远程更新桌面布局、同步节日/日程/天气等数据。
- **电源管理**：具备一键睡眠（关闭屏幕）和关机功能，延长电池续航。
- **音效反馈**：内置多种提示音效（开机、按键、闹钟等），支持音量与静音控制。

## 📂 项目结构

- `main.lua`: 项目主入口，负责初始化与任务调度。
- `devices.lua`: 硬件抽象层，定义按键、屏幕、蜂鸣器、ADC（电量检测）等设备驱动。
- `lvglfunc.lua` & `lvgl/`: 基于 LVGL 图形库的 UI 界面实现。
- `sounds.lua`: 音效管理模块。
- `wlanfunc.lua`: Wi-Fi 连接与 HTTP 网络请求（用于云端同步）。
- `glib/subc.lua`: 通用工具函数库（数据库、时间处理等）。
- `fonts/`: 项目使用的自定义中文字体文件。
- `weaicons/`: 天气图标资源。

## 🛠 使用说明

1.  **硬件准备**：需要一块支持本项目 BSP（如 ESP32-S3）的开发板，并连接好屏幕（ST7789 驱动）、四个按键和蜂鸣器。
2.  **烧录固件**：使用对应的 SDK 或工具链将本项目代码烧录至设备。
3.  **首次配置**：设备启动后，会进入 Wi-Fi 选择界面，选择网络并连接以完成首次配置和资源同步。
